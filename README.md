# 💜 Приглашение на свидание для Кристины

Милый, стильный и интерактивный сайт-приглашение в нежной фиолетовой гамме.

---

## ✨ Что внутри

1. **Главный экран с вопросом:**
   - Персонализированный заголовок: **«Привет, Кристина! ✨»**
   - Милая авторская анимация плюшевого мишки с сердечком
   - Интерактивная кнопка **«Да, с радостью! 🥰»** (увеличивается в размерах)
   - Убегающая кнопка **«Нет 🙈»** (при наведении или касании на телефоне забавно уворачивается и выдает поддразнивающие фразы)

2. **Пошаговый конструктор идеального вечера:**
   - **Шаг 1: Чем займемся** (романтичный ужин, кино, выставка/гончарка, вечерняя прогулка или сюрприз)
   - **Шаг 2: Вкусняшки** (итальянская кухня, суши и Азия, десерты, стейки, сюрприз)
   - **Шаг 3: Дата, время и секретный каприз** (удобный выбор дня, слоты времени и поле для особого пожелания)

3. **Финальный экран (Билет на свидание):**
   - Салют из конфетти в сиренево-розовых тонах
   - **VIP PASS ДЛЯ КРИСТИНЫ № LOVE-2026** со всеми её выборами
   - Кнопка **«Написать мне в Telegram»** (сразу открывает диалог с тобой с готовым текстом плана)
   - Кнопка **«Сохранить в календарь»** (скачивает `.ics` событие для Apple / Google Calendar)
   - Автоматическая отправка в Telegram-бот

---

## 🚀 Как запустить локально

В терминале в папке проекта запусти:
```bash
python3 -m http.server 3000
```
И открой в браузере: `http://localhost:3000`

## ⚙️ Как настроить получение ответа в Telegram

Есть два способа:

### Способ 1: Прямая ссылка на твой Telegram (Самый простой)
Нажми на незаметную иконку шестеренки **⚙️** в правом нижнем углу сайта и укажи свой username в Telegram (например, `alex_dev`).
Когда Кристина нажмет «Написать мне в Telegram», у неё откроется диалог с тобой с уже вставленным полным текстом её плана!

### Способ 2: Мгновенное уведомление через Telegram-бота (Автоматически)
1. Создай бота в [@BotFather](https://t.me/BotFather) за 1 минуту (`/newbot`) и скопируй токен.
2. Узнай свой Chat ID в боте [@userinfobot](https://t.me/userinfobot).
3. Введи их в меню настроек (⚙️) на сайте или передай в URL:
   `https://твой-сайт.ru/?token=ТВОЙ_ТОКЕН&chat_id=ТВОЙ_CHAT_ID&username=ТВОЙ_USERNAME`
Ответ прилетит тебе в бот в ту же секунду, как Кристина нажмет кнопку «Забронировать свидание»!

## 🌐 Как опубликовать сайт в интернет бесплатно

### Вариант 1: GitHub Pages (Бесплатно навсегда)
1. Создай репозиторий на GitHub и загрузи файлы (`index.html`, `style.css`, `script.js`).
2. Зайди в **Settings** -> **Pages** -> выбери ветку `main` -> **Save**.
3. Через минуту сайт будет доступен по ссылке: `https://твой-логин.github.io/date-site/`

### Вариант 2: Vercel или Netlify
- Перетащи папку проекта прямо в браузер на [vercel.com](https://vercel.com) или [netlify.com/drop](https://app.netlify.com/drop) — сайт опубликуется мгновенно!
